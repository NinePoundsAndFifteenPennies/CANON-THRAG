## 核心模块

### 1. 层次规范化：拆分、合并、软连接

输入为完整原始抽取 JSON 和 KV，不从已经聚合的 GEXF 猜测三元组或句子来源。`none` 保留原字符串 ID 形成的共享层级节点；`split` 根据父 Topic 对 Subtopic 建立作用域节点；`split_merge` 在拆分后先合并相容 Topic，再合并同一 canonical Topic 内的 Subtopic。节点身份与显示名称分开，旧 ID 可以对应多个新 ID，每条原始事实的两端路径分别保留。

每个层级节点有三种归一化原型：标签/aliases 均值、去重证据句向量均值、实体表面名称向量均值。上下文相容度为句子原型与实体原型相似度的加权和。标签近邻只生成候选；硬合并还要求标签与上下文分别通过阈值，并检查两个簇的所有原始成员对。不会通过单条相似边的传递闭包直接合并整簇。小候选组用精确近邻，大组用 FAISS HNSW 候选召回；实际合并门槛仍用原型的精确 cosine 判定。

规范标签取出现频率最高的现有标签，同频按字典序选择。原始 aliases、成员及来源映射保留。软边独立开关：在未硬合并的同层节点间，以较宽阈值构造互选近邻；跨父域 Subtopic 还要求所有父主题组合相容。软边用于扩散，不作为事实关系提供给回答模型。

硬规范化和仅软连接均可独立选择。只有标签相似、但来源语义冲突时，不应据此合并。新增 embedding 与离线处理有计算成本，不把它描述为零成本。

### 2. 主题/子主题选择：A、B 与融合版

路由统一返回 `(topic_id, subtopic_id)` 路径。关闭本模块时，由 `baseline` 适配器复用现有层次 LLM 选择器，并按父主题解析子主题身份；该名字是路由开关，不是作者源码对照实验预设。

**A：双端种子扩散。**底层种子由高相似证据句向其真实关联实体分配；顶层种子由标签相似度选出的 Topic/Subtopic 分配。两端按配置混合。层级边可双向传播，实体事实边保留，软边按开关加入。每个节点先按关系类型分配概率质量，再在该类型邻居间归一化，避免某类邻居数量直接吞没其他类型。

使用迭代 `p_next = restart * seed + (1 - restart) * P.T @ p`，孤立节点的质量回到种子。按相邻迭代的 L1 差停止，并设迭代上限；达到上限但未收敛时返回最后一轮分数并明确标记。固定少量迭代属于截断扩散，不把它写成已收敛 PPR。A 根据节点分数选择有明确预算的层次路径，随后统一获取实体；单独检索无需路由 LLM 客户端。

**B：证据卡片联合选择。**以标签 cosine 与下属 Top-n 证据句平均 cosine 加权激活节点，再生成候选路径。卡片提供父主题、子主题、匹配实体、相似度和短证据预览。一次 LLM 请求联合选择候选路径 ID，校验总数量、每个父主题的子主题数量和 ID 合法性。这里的分数不是校准概率。

**融合版：A 提候选，B 做最终选择。**A 与 B 通过分数和候选路径接口组合，单独 B 不依赖 A。候选按子主题排名交错排列；提示词超预算时先去除证据片段、保留实体与分数，再裁减尾部低排名路径。问题本身加一张卡片仍无法容纳时，在远端调用前报错。格式/暂时性错误有有限重试；耗尽后按候选分数顺序回退，记录实际调用数。认证、模型、schema 等永久 API 错误直接上报。

### 3. 证据分配：桥梁接力与分支覆盖

证据句只编码一次，但所有三元组、实体和 chunk 的关联以原始 occurrence 保留。实体倒排表确定完整候选子图，直接在候选内部排名；不使用全局 Top-K 预截断。两项证据增强都在 K1 截断前处理。

**桥梁接力。**从高分候选句的事实端点中取问题未直接提到的实体；实体匹配采用规范化表面词序列，不引入 NER 或额外 LLM。只对真正共享该实体、属于另一已选子主题分支的事实证据加一次分，并按实体事实度数衰减。排除同一句给自己加分，不在句子实体集合与全部来源间做笛卡尔积；不向路由子图外扩张。

**分支覆盖。**在完整候选池中选择不同 chunk，目标为

`F(C) = sum(r(c) for c in C) + coverage_weight * sum(max(r(c,b) for c in C) for b in selected_branches)`。

`r(c)` 是 chunk 内最好候选句的非负归一化分数；`r(c,b)` 只使用该 chunk 中实际属于所选路径 b 的 occurrence。贪心最大化边际收益，因此重复覆盖同一分支的收益递减。它不强制为每个分支分配名额，也不保证恢复完整多跳推理链。

均衡启用时先保留每个入选 chunk 的代表句，再按证据分数补齐 K1；K2 必须不大于 K1。桥梁与均衡分别可关；都关闭时按 cosine 取 K1，再扫描不同来源 chunk 至 K2。候选池为空时，显式记录回退到全图证据。

## 数据不变量和组合接口

原始抽取、KV、实体身份、事实文本和句子来源不改写。派生层级图、向量与结果放在独立命名空间。显示名称不能充当跨父域的节点主键；软边不能变成回答证据。三个模块通过统一路径和证据接口连接：关闭规范化仍可运行 A/B，关闭新路由仍可运行证据分配。

具体配置含义由 [配置参考](config_reference.md#canon) 维护，参数初值只在 [模板](../thrag/.env.example) 详细列出；初值没有实验最优性的含义。代码结构见 [源码导航](../thrag/README.md#canon)，运行和产物布局见 [服务器说明](../thrag/SETUP_GUIDE.md#canon)。

<a id="validation"></a>
## 消融与实现验收边界

最终与作者源码运行结果的比较由用户自行组织。实现不设置 `fixed` 修复版基线，不自动执行作者对照，不生成修复收益或贡献归因报告。可选任务清单仅展开三模块开关，以及路由、规范化、证据分配的组件选择；每个任务仍需用户在服务器运行。

回归用例检查来源完整性、作用域节点、合并相容性、扩散与调用预算、证据覆盖和缓存隔离。代码与测试用例写入不等于测试通过，也不等于论文复现实验。完整 gold evidence→chunk 映射、chunk 指标及质量实验不在本轮实现范围；现有评测限制见 [资源审计](resource_audit.md#evaluation)。

<a id="contribution"></a>
## 研究结论的边界

这三个模块是待验证方法。预筛、软边、扩散和均衡都可能引入漏选或噪声，不能预先保证涨点或指定延迟降幅。不会依据论文图的平均邻接数推断当前语料的分支分布。论文叙事和保留哪种组合由用户根据后续结果决定。

## 非核心扩展

动态 K1/K2、query expansion、cross-encoder、额外实体扩展、反思和额外 LLM 合并裁决均未自动纳入本轮实现。
